# MP 收款播报 — 安装包发布

这里只存放 **MP 收款播报** 桌面版的安装包，供软件内「检查更新」使用。不含源代码。

## 下载

到 [Releases](../../releases) 页取最新版本：

| 文件 | 适用系统 |
| --- | --- |
| `MP_Setup.exe` | Windows 10 / 11（64 位） |
| `MP_Setup_Win7_32.exe` | Windows 7（32 位） |

覆盖安装即可，收款记录、Access Token、授权码都会保留。

## 关于自动更新

软件启动后会自动检查这里的最新 Release。发现新版时首页顶部会出现提示，点「立即更新」即可自动下载安装并重新打开。
